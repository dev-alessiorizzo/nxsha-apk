## 🚀 Getting Started

### 📱 On Android

1. Visit **https://nxsha.app/**
2. Download the APK compatible with your device.
3. Install Nxsha.
4. Open the app and start exploring.

**Which APK should you download?**

- **32-bit:** Older Android phones and supported TVs.
- **64-bit:** Most modern Android phones and compatible TVs.
- **Universal:** Recommended if you're unsure which version your device supports.
- **x86 / x86_64:** For compatible Android emulators.

For a fresh installation, you can uninstall an older version first. Be aware this may delete saved history, settings, and downloads.

### 🌐 On Web

Don't want to install anything?

Simply visit:

**https://nxsha.space/**

Open the website in your browser and start exploring.
